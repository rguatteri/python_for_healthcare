# Outpatient Visit Analysis

This notebook analyses a demonstration outpatient-clinic dataset to examine patient flow and identify potential sources of delay across the visit pathway.

## Analysis

The workflow uses **pandas** to load and prepare visit-level data, then calculates total waiting time by combining time spent in registration, nursing, laboratory, consultation, and pharmacy. It applies descriptive statistics, trend analysis, and visualisations to explore wait-time patterns, patient demographics, visit costs, and relationships between variables.

## Files

- `01_outpatient_visit_analysis.ipynb` — Jupyter Notebook containing the complete analysis.

## Tools

Python, pandas, matplotlib, seaborn, and plotly.
